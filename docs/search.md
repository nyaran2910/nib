# 4 種類の fzf ファジー検索とタグ管理

Nib はフォルダを開いたタイミングで Rust 側の `SearchIndex` が配下の Markdown ファイルを一括インデックスし、以降の保存・作成・削除で自動更新します。

検索モーダル内では **`Tab` / `Shift+Tab`** で 4 つの検索モードをシームレスに切り替えられ、`↑↓` / `Ctrl+N`・`Ctrl+P` で候補移動、`Enter` で該当ノート（および該当行）へジャンプします。

## 1. Omni Search (`Cmd+K`)

Obsidian の Omnisearch に着想を得た総合検索です。**ファイル名・タグ・本文** のすべてを重み付けファジー評価します。

- クエリ内に `#tag` を混ぜることも可能です（例: `#work rust` で `#work` タグ付きノートから `rust` を検索）。

## 2. ファイル名検索 (`Cmd+Shift+O`)

fzf 風のサブシーケンス一致 + 単語境界ボーナス（`/`・`-`・`_`・camelCase）で、ノートタイトルおよび相対パスを高速に曖昧検索します。

## 3. 本文検索 (`Cmd+Shift+F`)

すべての Markdown ファイルの本文を行単位で検索し、スニペットと行番号 (`L42`) を表示します。決定すると CodeMirror 6 が該当行へ直接スクロール・フォーカスします。

## 4. タグ検索 & 絞り込み (`Cmd+Shift+T`)

以下の両形式のタグを自動抽出します（コードブロック内の `#` や 16 進カラーコードは除外）。

1. **インラインタグ**: `#rust`, `#project/nib`（ネストタグ対応）
2. **YAML フロントマター**:
   ```yaml
   ---
   tags: [guide, project/nib]
   ---
   ```

タグ検索モードではファジーにタグを絞り込み、タグチップをクリックして対象ノートを一覧表示できます。ネストタグ（例: `#project` を選択すると `#project/nib` もヒット）にも対応しています。
